Design decisions

Decision Rationale Tradeoff Evidence
Express strategies as IStrategy callback subclasses. Keeps examples small and delegates exchange/order/portfolio mechanics to host. Usability depends on host interface and external indicator dependency compatibility. Strategy001 (L13) / UniversalMACD (L21)

Strengths and limits

Strengths

  • Example callback bodies expose exactly which indicators and conditions produce entry/exit columns. Strategy001.populate_indicators (L74) / Strategy001.populate_entry_trend (L93) / UniversalMACD.populate_entry_trend (L96)

Limitations

  • Educational examples and stored optimizer result comments do not establish profitability or readiness on current markets. README.md (L3) / UniversalMACD (L21)

Validation scope

The linked validation and command records preserve actual historical runs and user-authorized exclusions. This source/document review does not rerun application tests, establish live trading readiness or rank benchmark performance. Current data, credential and runtime prerequisites remain material.
